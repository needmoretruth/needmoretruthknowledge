**nmtk** — *need more truth knowledge* — 는 어려운 것 몇 가지가 실제로 어떻게 돌아가는지를, 내 컴퓨터에서
직접 돌려 보고 돌아가는 중에 값을 바꿔 보면서 배우는 터미널 프로그램입니다.

채굴 애니메이션이 아닙니다. 내 코어가 실제로 해시를 돌립니다. 51% 공격 그림이 아닙니다. 내 컴퓨터의 일부를
떼어 준 공격자가 실제로 체인을 다시 쓰고 이미 받은 코인을 실제로 되가져갑니다.

전부 로컬에서 돌아갑니다. nmtk는 네트워크에 연결하지 않고, 아무것도 보내지 않으며, 계정도 필요 없습니다.

## 지식 퀘스트 (Knowledge Quest)

**KQ** 하나는 완결된 배움 한 덩이이고, 가르치는 대신 말을 겁니다.

한두 문장으로 한 가지를 말해 줍니다. Enter를 누릅니다. 이 컴퓨터에서 진짜로 무슨 일이 일어납니다. 그리고
방금 일어난 일에 대해 한 문장. 다시 Enter. 교과서가 아니라 메신저가 흘러가는 방식입니다. 답이 나오는 데
시간이 걸리는 곳에서는 대화가 멈추고 기다립니다. 블록이 나오고, 손실이 어떤 선을 넘고, 공격이 포기하는
순간마다 그 자리에서 말해 줍니다.

퀘스트마다 단계가 최소 셋이고 많으면 일곱입니다. 단계마다 난이도가 따로 있어서 아주 쉽게 시작해 어렵게
끝날 수 있고, `Tab`으로 단계 사이를 옮깁니다.

| 단계의 성격 | 하는 일 |
|---|---|
| **왜** | 이것이 왜 시간을 들일 만한가. 한 번에 한 문장씩. |
| **실행** | 진짜가 돕니다. 미리 정해진 결과는 없습니다. |
| **조절** | 값을 바꾸면 — 화살표로든 숫자를 직접 쳐서든 — 실행이 답합니다. |
| **무너뜨리기** | 공격해 보고 무엇이 버티는지 압니다. |
| **정리** | 방금 일어난 일을, 내가 만든 숫자로. |

지금 퀘스트 넷이 들어 있습니다.

### ⛏ 작업증명 · *합의 · 40분*

진짜 비트코인 블록 헤더 — 80바이트, 이중 SHA-256, 진짜 목표값과 비교 — 를 연습 난이도로 캡니다. 그래서
블록이 몇 초 만에 나옵니다. 실측한 내 해시 속도 옆에, 그것이 비트코인 난이도 1에서 무슨 뜻인지와,
프로토콜이 말해 주는 2009년 초 네트워크 속도가 함께 놓입니다. 요즘 노트북 한 대가 2009년 1월 네트워크
전체의 몇 배입니다.

그다음 내 코어를 원하는 비율로 채굴자들에게 나눠 주고 체인을 공격합니다. 30%에서는 공격자가 뒤처지다
포기하고 결제는 그대로 남습니다. 거기서 `51`을 쳐 같은 공격을 다시 돌리면 그것이 **실제로 성공하는 51%
공격**입니다 — 정한 확인 수만큼 결제가 확정되고, 상인이 물건을 건네고, 공격자의 비밀 체인이 그 결제를
지웁니다.

### 📒 원장 방식 · *원장 · 20분*

코인 하나를 세 가지 규칙에 동시에 넣습니다 — **UTXO**(비트코인) · **계정 중심**(이더리움) ·
**객체 중심**(Sui). 잔액만 빼고 전부 다릅니다. 같은 이체 하나에 UTXO는 상태가 그대로이고, 계정 방식은
계정이 통째로 하나 새로 생기고, 객체 방식은 다시 그대로입니다.

그다음 같은 코인을 두 번 씁니다. 셋 다 막는데, 서로 다른 단계에서 서로 다른 이유로 막습니다. 코인이 이미
쓰였거나, 번호가 이미 넘어갔거나, 객체가 더 새 판으로 넘어갔습니다.

### 🧠 트랜스포머 · *기계학습 · 45분*

어텐션·피드포워드·레이어 정규화·역전파까지 전부 손으로 짠 진짜 트랜스포머입니다. 밑에 깔린 기계학습
프레임워크가 없습니다. 가중치 십만 개쯤을 여기서 30초 남짓 학습시키면, `nmtk`라고 물었을 때
`need more truth knowledge`라고 답합니다.

손실이 내려가는 것과 어텐션 격자가 채워지는 것을 봅니다. 그다음 층·헤드·너비·학습률을 바꿔 다시
학습시키고, **무너뜨리기** 단계에서는 학습률을 3000배로 올려 같은 모델이 같은 글자만 되풀이하며
무너지는 것을 봅니다.

### 🔒 영지식 증명 · *암호 · 50분*

실제 계보를 순서대로, 각각 여기서 돌려 가며 따라갑니다. 주고받는 **시그마 프로토콜**(메시지 하나하나
따라가 봅니다), 같은 증명을 주고받지 않아도 되게 바꾼 **피아트-샤미르**, **설정에 쓴 난수를 없앴다는
전제** 위에 선 방식, 그리고 그런 설정이 필요 없는 **halo2**. 증명 시간·검증 시간·증명 크기가 나란히
놓입니다 — 한쪽 끝은 96바이트에 1밀리초도 안 걸리고, 다른 쪽 끝은 1.5KiB에 수십 밀리초입니다.

그다음 넷 모두를 공격합니다. 응답을 찍으면 거절됩니다. 커밋먼트를 빠뜨린 피아트-샤미르 챌린지는 위조가
**통과**합니다. 그리고 신뢰 설정에서 남은 난수를 쥔 사람이 커밋먼트를 그 안에 없는 값으로 열면, 손대지
않은 검증자가 그것도 받아들입니다. 사람들이 「그 의식이 정직했나」를 따지는 이유가 이것입니다.

마지막으로 같은 가려진 결제를 네 사람의 눈으로 동시에 봅니다 — 보낸 사람, 받는 사람, 지켜보는 사람,
공격자.

## 설치

페도라나 우분투 터미널에 아래 한 줄을 붙여 넣으세요. 필요한 것을 설치하고 바로 실행되며, 중간에 아무것도
묻지 않습니다.

```sh
git clone https://github.com/needmoretruth/needmoretruthknowledge.git && cd needmoretruthknowledge && ./install.sh
```

자세한 설명과 다른 설치 방법, 잘 안 될 때의 해결법은 **[INSTALL.ko.md](INSTALL.ko.md)**에 있습니다.

## 키

시작할 때 알아야 할 키는 `Enter` 하나뿐입니다.

| 키 | 하는 일 |
|---|---|
| `Enter` | 대화를 이어 가기 — 값을 정하는 단계에서는 화면의 값으로 실행하기 |
| `Tab` | 퀘스트의 다음 단계 (`Shift+Tab`은 앞 단계) |
| `↑` `↓` | 바꿀 값 고르기 |
| `←` `→` 또는 `0`–`9` | 그 값 바꾸기. 화살표로도, 원하는 숫자를 직접 쳐서도 |
| `PgUp` `PgDn` | 지나간 대화 되돌려 보기 |
| `Space` | 실행 일시정지와 재개 |
| `r` | 이 단계를 처음부터 다시 |
| `o` `f` | 목록에서: 정렬과 분류 |
| `l` | 언어 고르기 |
| `s` | 설정 |
| `?` | 어디서 쓰는 키인지까지 묶어서 보여 주는 키 목록 |
| `q` 또는 `Esc` | 뒤로, 목록에서는 끝내기 |

터미널이 최소 80×24는 돼야 합니다.

## 언어

nmtk를 처음 켜면 이것이 무엇인지 네 줄로 말해 주고 세 가지를 묻습니다. 그 첫 번째가 언어입니다. 그다음부터는
다시 묻지 않고, 어디서든 `l`을 누르면 목록이 열립니다.

영어가 기본이고 항상 빠짐없이 채워져 있습니다. 아직 번역되지 않은 줄은 비워 두지 않고 영어로 남으며, 어떤
화면도 한 언어에서는 보이는 내용을 다른 언어에서 잃지 않습니다.

## 설정

nmtk는 시작할 때 이 컴퓨터를 보고 작업 크기를 맞춥니다. 코어가 넷인 노트북에 한 시간짜리 작업을 주지
않습니다. 퀘스트마다 **최소 사양**과 **권장 사양**이 적혀 있고, 목록에서 내 컴퓨터가 그 둘 중 어디에
서는지 말해 줍니다. 최소 사양에 못 미쳐도 퀘스트는 열리고 크기를 줄여 돌며, 그 사실을 화면에 적습니다.

스레드 수·언어·색은 `s`에서 바꿀 수 있고, 바꾼 값은 `~/.config/nmtk/settings.toml`에 남습니다.
그 파일에는 끝낸 퀘스트의 id도 함께 남아서, 목록이 그것을 표시해 줍니다. nmtk가 내가 한 일에 대해
기록하는 것은 이것뿐이고, 이 컴퓨터 밖으로 나가지 않습니다.

퀘스트에는 판 번호가 있고, 한 번의 배포에는 퀘스트마다 가장 새 판 하나만 들어갑니다. 이전 판은 남기지
않습니다. 내가 배운 그 판을 다시 보고 싶으면 이 저장소에서 그 판의 커밋을 받아 빌드하면 됩니다. 기록이
전부 거기에 있고, 저장소는 원래 그러라고 있는 것입니다.

## nmtk가 하지 않는 것

- **네트워크를 쓰지 않습니다.** 업데이트 확인도, 사용 기록 전송도, 그 무엇도 하지 않습니다.
- **계정도, 키도, 지갑도 없습니다.** 여기 있는 것은 실제 돈이나 실제 체인과 닿지 않습니다.
- **보이지 않는 계산이 없습니다.** 화면의 모든 숫자는 이 컴퓨터에서 실제로 돌아간 것에서 나옵니다.

## 퀘스트 만들기

퀘스트는 하나의 표준 위에서 만들어집니다. 서로 다른 사람이 만든 넷이 한 프로그램처럼 느껴지는 이유입니다:
**[docs/KQ-STANDARD.md](docs/KQ-STANDARD.md)**. 퀘스트가 자기에 대해 무엇을 밝혀야 하는지, 대화를 어떻게
쓰는지, 단계와 난이도, 최소·권장 사양, 화면 구성, 네 가지 상태 색, 키, 그리고 그 모두를 관통하는 기준 —
읽는 사람이 무언가를 바꾸고 그 결과를 볼 수 있어야 그 주제가 끝난 것입니다 — 이 담겨 있습니다.

이슈와 풀 리퀘스트를 환영합니다.
