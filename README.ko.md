**nmtk** — *need more truth knowledge* — 는 어려운 것 몇 가지가 실제로 어떻게 돌아가는지를, 내 컴퓨터에서
직접 돌려 보고 돌아가는 중에 값을 바꿔 보면서 배우는 터미널 프로그램입니다.

채굴 애니메이션이 아닙니다. 내 코어가 실제로 해시를 돌립니다. 51% 공격 그림이 아닙니다. 내 컴퓨터의 일부를
떼어 준 공격자가 실제로 체인을 다시 쓰고 이미 받은 코인을 실제로 되가져갑니다.

전부 로컬에서 돌아갑니다. nmtk는 네트워크에 연결하지 않고, 아무것도 보내지 않으며, 계정도 필요 없습니다.

## 지식 퀘스트 (Knowledge Quest)

**KQ** 하나는 완결된 배움 한 덩이입니다. 모든 퀘스트가 같은 다섯 단계를 지나므로, 하나를 해 보면 나머지도
어디에 무엇이 있는지 알게 됩니다.

| | 단계 | 하는 일 |
|---|---|---|
| `1` | **왜** | 이것이 왜 시간을 들일 만한가. 한 화면, 어려운 말 없이. |
| `2` | **실행** | 진짜가 돕니다. 숫자가 움직입니다. 미리 정해진 결과는 없습니다. |
| `3` | **조절** | 값을 바꾸면 실행이 답합니다. |
| `4` | **무너뜨리기** | 공격해 보고 무엇이 버티는지 압니다. |
| `5` | **정리** | 방금 일어난 일을, 일어난 순서대로. |

지금 넷이 들어 있습니다.

### ⛏ 작업증명 · *합의 · 40분*

진짜 비트코인 블록 헤더 — 80바이트, 이중 SHA-256, 진짜 목표값과 비교 — 를 연습 난이도로 캡니다. 그래서
블록이 몇 초 만에 나옵니다. 실측한 내 해시 속도 옆에, 그것이 비트코인 난이도 1에서 무슨 뜻인지와,
프로토콜이 말해 주는 2009년 초 네트워크 속도가 함께 놓입니다. 요즘 노트북 한 대가 2009년 1월 네트워크
전체의 몇 배입니다.

그다음 내 코어를 원하는 비율로 채굴자들에게 나눠 주고 **실제로 성공하는 51% 공격**을 돌립니다. 정한 확인
수만큼 결제가 확정되고, 상인이 물건을 건네고, 공격자의 비밀 체인이 그 결제를 지웁니다. 공격자를 30%로
낮추면 같은 공격이 뒤처지다 포기하는 것을 봅니다.

### 📒 원장 방식 · *원장 · 25분*

코인 하나를 세 가지 규칙에 동시에 넣습니다 — **UTXO**(비트코인) · **계정 중심**(이더리움) ·
**객체 중심**(Sui). 잔액만 빼고 전부 다릅니다. 같은 이체 하나에 UTXO는 상태가 그대로이고, 계정 방식은
계정이 통째로 하나 새로 생기고, 객체 방식은 다시 그대로입니다.

그다음 같은 코인을 두 번 씁니다. 셋 다 막는데, 서로 다른 단계에서 서로 다른 이유로 막습니다. 코인이 이미
쓰였거나, 번호가 이미 넘어갔거나, 객체가 더 새 판으로 넘어갔습니다.

### 🧠 트랜스포머 · *기계학습 · 45분*

어텐션·피드포워드·레이어 정규화·역전파까지 전부 손으로 짠 진짜 트랜스포머입니다. 밑에 깔린 기계학습
프레임워크가 없습니다. 가중치 십만 개쯤을 여기서 30초 남짓 학습시키면, `nmtk`라고 물었을 때
`need more truth knowledge`라고 답합니다.

손실이 내려가는 것과 어텐션 격자가 채워지는 것을 봅니다. 그다음 층·헤드·너비·학습률을 바꿔 다시
학습시키고, **무너뜨리기** 단계에서는 학습률을 3000배로 올려 같은 모델이 같은 글자만 되풀이하며
무너지는 것을 봅니다.

### 🔒 영지식 증명 · *암호 · 50분*

실제 계보를 순서대로, 각각 여기서 돌려 가며 따라갑니다. 주고받는 **시그마 프로토콜**(메시지 하나하나
따라가 봅니다), 같은 증명을 주고받지 않아도 되게 바꾼 **피아트-샤미르**, **설정에 쓴 난수를 없앴다는
전제** 위에 선 방식, 그리고 그런 설정이 필요 없는 **halo2**. 증명 시간·검증 시간·증명 크기가 나란히
놓입니다 — 한쪽 끝은 96바이트에 1밀리초도 안 걸리고, 다른 쪽 끝은 1.5KiB에 수십 밀리초입니다.

그다음 넷 모두를 공격합니다. 응답을 찍으면 거절됩니다. 커밋먼트를 빠뜨린 피아트-샤미르 챌린지는 위조가
**통과**합니다. 그리고 신뢰 설정에서 남은 난수를 쥔 사람이 커밋먼트를 그 안에 없는 값으로 열면, 손대지
않은 검증자가 그것도 받아들입니다. 사람들이 「그 의식이 정직했나」를 따지는 이유가 이것입니다.

마지막으로 같은 가려진 결제를 네 사람의 눈으로 동시에 봅니다 — 보낸 사람, 받는 사람, 지켜보는 사람,
공격자.

## 설치

nmtk는 소스에서 빌드합니다. Rust 1.96 이상이 필요하고, 저장소가 컴파일러 판을 고정해 두었으므로 `rustup`이
맞는 판을 알아서 받아 옵니다.

```sh
# Rust가 아직 없다면
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

git clone https://github.com/needmoretruth/needmoretruthknowledge.git
cd needmoretruthknowledge
cargo build --release
./target/release/nmtk
```

어디서나 `nmtk`로 실행하고 싶다면:

```sh
cargo install --path crates/nmtk
nmtk
```

**페도라**와 **우분투**에서 다른 패키지는 필요 없습니다. nmtk는 Rust 밖의 라이브러리를 쓰지 않습니다.

## 키

| 키 | 하는 일 |
|---|---|
| `↑` `↓` 또는 `j` `k` | 이동 |
| `Enter` | 열기, 실행, 입력한 숫자 확정 |
| `←` `→` | 고른 값 바꾸기 |
| `1`–`5` | 단계로 바로 가기 |
| `Space` | 일시정지와 재개 |
| `r` | 초기화 |
| `o` `f` `v` | 목록에서: 정렬, 분류, 이전 판 |
| `l` | English ⇄ 한국어 |
| `s` | 설정 |
| `?` | 키 |
| `q` 또는 `Esc` | 뒤로, 목록에서는 끝내기 |

터미널이 최소 80×24는 돼야 합니다.

## 언어

영어가 기본이고 항상 빠짐없이 채워져 있습니다. 한국어는 `l` 키 하나로 바뀌며, 아직 번역되지 않은 줄은
비워 두지 않고 영어로 남습니다.

## 설정

nmtk는 시작할 때 이 컴퓨터를 보고 작업 크기를 맞춥니다. 코어가 넷인 노트북에 한 시간짜리 작업을 주지
않습니다. 스레드 수·언어·색은 `s`에서 바꿀 수 있고, 바꾼 값은 `~/.config/nmtk/settings.toml`에 남습니다.

퀘스트에는 판 번호가 있습니다. 내가 배운 퀘스트가 어느 날 말없이 다른 것으로 바뀌는 일은 없습니다. 새 판이
나와도 이전 판은 프로그램에 그대로 남고, 목록에서 `v`를 누르면 내가 봤던 바로 그 판을 열 수 있습니다.

## nmtk가 하지 않는 것

- **네트워크를 쓰지 않습니다.** 업데이트 확인도, 사용 기록 전송도, 그 무엇도 하지 않습니다.
- **계정도, 키도, 지갑도 없습니다.** 여기 있는 것은 실제 돈이나 실제 체인과 닿지 않습니다.
- **보이지 않는 계산이 없습니다.** 화면의 모든 숫자는 이 컴퓨터에서 실제로 돌아간 것에서 나옵니다.

## 퀘스트 만들기

퀘스트는 하나의 표준 위에서 만들어집니다. 서로 다른 사람이 만든 넷이 한 프로그램처럼 느껴지는 이유입니다:
**[docs/KQ-STANDARD.md](docs/KQ-STANDARD.md)**. 퀘스트가 자기에 대해 무엇을 밝혀야 하는지, 다섯 단계,
화면 구성, 네 가지 상태 색, 키, 그리고 그 모두를 관통하는 기준 — 읽는 사람이 무언가를 바꾸고 그 결과를 볼
수 있어야 그 주제가 끝난 것입니다 — 이 담겨 있습니다.

이슈와 풀 리퀘스트를 환영합니다.
