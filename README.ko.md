**nmtk** — *need more truth knowledge* — 는 어려운 것 몇 가지가 실제로 어떻게 돌아가는지를, 내 컴퓨터에서
직접 돌려 보고 돌아가는 중에 값을 바꿔 보면서 배우는 터미널 프로그램입니다.

채굴 애니메이션이 아닙니다. 내 코어가 실제로 해시를 돌립니다. 51% 공격 그림이 아닙니다. 내 컴퓨터의 일부를
떼어 준 공격자가 실제로 체인을 다시 쓰고 이미 받은 코인을 실제로 되가져갑니다.

전부 로컬에서 돌아갑니다. nmtk는 네트워크에 연결하지 않고, 아무것도 보내지 않으며, 계정도 필요 없습니다.

## 무엇을 돌려 볼 수 있나

### ⛏ 작업증명

비트코인이 처음 나왔을 때의 난이도로 채굴해 보고, 2009년 1월에 내 컴퓨터라면 어땠을지 확인합니다. 그다음
연습용 난이도를 정하면 블록이 몇 초 만에 나옵니다. 내 코어를 채굴자들에게 원하는 비율로 나눠 주고,
**실제로 성공하는 51% 공격**을 돌립니다. 공격자가 몰래 체인을 쌓고, 이미 확정된 것으로 보였던 결제가
취소되고, 그것이 몇 확인을 되돌린 것인지 화면에 나옵니다. 공격자 몫을 30%로 낮추면 이번에는 실패하는 것을
봅니다.

### 📒 원장 방식

같은 코인을 세 가지 규칙으로 보냅니다. **UTXO**(비트코인) · **계정 중심**(이더리움) · **객체 중심**(Sui).
세 곳에서 각각 두 번 쓰기를 시도해 보고, 거절되는 이유가 셋 다 다른 것을 봅니다. 어떤 두 결제가 동시에
처리될 수 있는지, 그리고 어디서 그 가능성이 사라지는지도 봅니다.

### 🧠 트랜스포머

어텐션, 피드포워드, 레이어 정규화, 역전파까지 전부 손으로 짠 진짜 트랜스포머입니다. 밑에 깔린 기계학습
프레임워크가 없습니다. `nmtk`라고 하면 `need more truth knowledge`라고 답할 때까지 여기서 직접 학습시키고,
손실이 내려가는 것과 어텐션이 어디를 보는지 지켜봅니다. 그다음 층 수·헤드 수·너비·학습률을 바꿔 다시
학습시킵니다.

### 🔒 영지식 증명

무언가를 보여 주지 않고 안다는 것만 증명합니다. 실제 계보를 순서대로 따라갑니다. 주고받는 방식의 시그마
프로토콜, 같은 증명을 주고받지 않아도 되게 바꾼 것, 설정에 쓴 난수를 없앴다는 전제 위에 선 방식 — 그 비밀을
가진 공격자가 실제로 가짜 증명을 통과시키는 것을 봅니다 — 그리고 마지막으로 그런 설정이 필요 없는
**halo2**. 각 단계를 네 사람의 눈으로 동시에 봅니다: 보낸 사람, 받는 사람, 지켜보는 사람, 공격자.

## 설치

nmtk는 소스에서 빌드합니다. Rust 1.96 이상이 필요하고, 저장소가 컴파일러 판을 고정해 두었으므로 `rustup`이
맞는 판을 알아서 받아 옵니다.

```sh
# Rust가 아직 없다면
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

git clone https://github.com/needmoretruth/needmoretruthknowledge.git
cd needmoretruthknowledge
cargo build --release
./target/release/nmtk
```

어디서나 `nmtk`로 실행하고 싶다면:

```sh
cargo install --path crates/nmtk
nmtk
```

**페도라**와 **우분투**에서 다른 패키지는 필요 없습니다. nmtk는 Rust 밖의 라이브러리를 쓰지 않습니다.

## 키

| 키 | 하는 일 |
|---|---|
| `↑` `↓` 또는 `j` `k` | 이동 |
| `Enter` | 열기, 또는 실행 시작 |
| `Space` | 일시정지와 재개 |
| `r` | 초기화 |
| `Tab` | 패널 이동 |
| `l` | English ⇄ 한국어 |
| `s` | 설정 |
| `?` | 키 |
| `q` 또는 `Esc` | 뒤로, 첫 화면에서는 끝내기 |

터미널이 최소 80×24는 돼야 합니다.

## 언어

영어가 기본이고 항상 빠짐없이 채워져 있습니다. 한국어는 `l` 키 하나로 바뀌며, 아직 번역되지 않은 줄은
비워 두지 않고 영어로 남습니다.

## 설정

nmtk는 시작할 때 이 컴퓨터를 보고 작업 크기를 맞춥니다. 코어가 넷인 노트북에 한 시간짜리 작업을 주지
않습니다. 스레드 수·언어·색은 `s`에서 바꿀 수 있고, 바꾼 값은 `~/.config/nmtk/settings.toml`에 남습니다.

## nmtk가 하지 않는 것

- **네트워크를 쓰지 않습니다.** 업데이트 확인도, 사용 기록 전송도, 그 무엇도 하지 않습니다.
- **계정도, 키도, 지갑도 없습니다.** 여기 있는 것은 실제 돈이나 실제 체인과 닿지 않습니다.
- **보이지 않는 계산이 없습니다.** 화면의 모든 숫자는 이 컴퓨터에서 실제로 돌아간 것에서 나옵니다.
